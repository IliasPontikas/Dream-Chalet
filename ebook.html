Foundation 1

What is JavaScript?

You already know HTML and CSS. HTML is the skeleton of a page — the structure. CSS is the skin — colors, fonts, layout. JavaScript is the brain — it makes things happen. It responds to clicks, fetches data from the internet, animates elements, validates forms, and controls every interactive thing on a modern website.

JavaScript runs directly in the browser. You do not need to install anything. You do not need a server. You write it, the browser executes it.

Where Does JavaScript Live?

<!-- Option 1: Inline (avoid for anything longer than 1 line) -->
<button onclick="alert('Hello!')">Click me</button>

<!-- Option 2: Internal <script> tag (fine for learning, avoid in production) -->
<script>
  console.log("Hello from internal script");
</script>

<!-- Option 3: External file (always do this in real projects) -->
<script src="js/main.js"></script>
Rule: Always put your <script> tag just before the closing </body> tag. This ensures your HTML is fully loaded before JavaScript tries to interact with it.

The Browser Console — Your Best Friend

The console is a built-in tool in every browser where you can run JavaScript live, see errors, and print messages. Open it with F12 (or Cmd+Option+I on Mac) → click the Console tab.

// Print a message to the console
console.log("Hello, world!");

// Print a number
console.log(42);

// Print multiple things at once
console.log("My name is", "Ilias", "and I am", 28, "years old");

// Print an error (shows in red)
console.error("Something went wrong!");

// Print a warning (shows in yellow)
console.warn("This might be a problem");

// Print a table (great for arrays of objects)
console.table([{ name: "Meteora", km: 22 }, { name: "Elati", km: 30 }]);

From now on, while learning: console.log() everything. It is how you see what your code is doing.

Variables & Data Types

A variable is a named container for storing a value. Think of it like a labelled box — you put something in it, give it a name, and refer to it by that name later.

Declaring Variables

// const — value cannot be reassigned (use this by default)
const siteName = "Dream Chalet";
const nightlyRate = 130;

// let — value CAN be reassigned (use when value will change)
let currentGuests = 2;
currentGuests = 4; // OK — let allows reassignment

// var — old way, avoid it in modern JavaScript
var oldStyle = "don't use this";
Rule of thumb: Always use const first. If you later need to reassign it, change it to let. Never use var.

Foundation 3

Functions & Scope

A function is a reusable block of code with a name. Instead of writing the same logic 10 times, you write it once inside a function and call it 10 times. Functions are the building blocks of every JavaScript program.

Function Declaration

// Declare (define) the function
function greetGuest(name) {
  console.log("Welcome, " + name + "!");
}

// Call (execute) the function
greetGuest("Maria");  // Welcome, Maria!
greetGuest("Nikos");  // Welcome, Nikos!

Parameters and Return Values

// Parameters are inputs. Return sends a value back.
function calculateTotal(pricePerNight, nights, discountPercent) {
  const subtotal = pricePerNight * nights;
  const discount = subtotal * (discountPercent / 100);
  const total    = subtotal - discount;
  return total; // send the result back to whoever called us
}

// Use the returned value
const cost = calculateTotal(130, 5, 10);
console.log(cost); // 585

// Default parameters — value used when argument is not provided
function greet(name, lang = "el") {
  if (lang === "el") return "Καλωσήρθατε, " + name;
  return "Welcome, " + name;
}
console.log(greet("Maria"));        // Καλωσήρθατε, Maria
console.log(greet("John", "en"));   // Welcome, John

Function Expressions

// Store a function in a variable
const calculateTotal = function(price, nights) {
  return price * nights;
};

console.log(calculateTotal(130, 3)); // 390

Arrow Functions — Modern Syntax

Arrow functions are a shorter way to write functions. You will see them everywhere in modern JavaScript — in GSAP callbacks, event listeners, array methods.

// Regular function
function double(n) { return n * 2; }

// Arrow function — equivalent
const double = (n) => { return n * 2; };

// Even shorter: if body is just a return, skip the braces and "return"
const double = n => n * 2;

console.log(double(5)); // 10

// Multiple parameters
const add = (a, b) => a + b;
console.log(add(3, 4)); // 7

// No parameters
const sayHello = () => console.log("Hello!");
sayHello();

// Arrow function in a callback (very common)
setTimeout(() => {
  console.log("1 second passed!");
}, 1000);

Scope — Where Variables Live

// Global scope — declared outside any function, accessible everywhere
const siteName = "Dream Chalet"; // global

function showSite() {
  console.log(siteName); // ✓ can access global variable
}

// Local (function) scope — declared inside a function, only exists there
function calculatePrice() {
  const discount = 0.1; // local — only exists inside this function
  return 130 * (1 - discount);
}

console.log(discount); // ✗ ReferenceError: discount is not defined

// Block scope — let and const declared inside {} only exist in that block
if (true) {
  let blockVar = "I only exist here";
  const alsoBlock = "me too";
}
console.log(blockVar); // ✗ ReferenceError

// Closures — a function that remembers variables from its outer scope
function makeCounter() {
  let count = 0;           // this variable is "closed over"
  return function() {
    count++;
    return count;
  };
}
const counter = makeCounter();
console.log(counter()); // 1
console.log(counter()); // 2
console.log(counter()); // 3
Common mistake: Declaring the same variable twice with const or using a variable before declaring it. Always declare variables at the top of their scope.

Immediately Invoked Function Expression (IIFE)

A pattern you will see in library code — a function that runs immediately as soon as it is defined. Keeps variables private and avoids polluting the global scope.

// Regular function — must be called separately
function init() { console.log("init!"); }
init();

// IIFE — declares AND calls in one go
(function() {
  console.log("I run immediately!");
  const privateVar = "no one outside can see me";
})();

// Arrow function IIFE
(() => {
  console.log("Also immediate!");
})();

Foundation 4

Arrays, Objects & Loops

Arrays and objects are the two most important data structures in JavaScript. Everything you do with GSAP, MapLibre, i18next, and Three.js involves working with arrays and objects. Master these and the rest follows naturally.

Arrays

An array is an ordered list. Items are accessed by their position (index), starting from 0.

// Create an array
const amenities = ["WiFi", "Fireplace", "Parking", "Garden", "Kitchen"];

// Access items by index (starts at 0)
console.log(amenities[0]); // "WiFi"
console.log(amenities[2]); // "Parking"
console.log(amenities[amenities.length - 1]); // "Kitchen" (last item)

// Modify an item
amenities[1] = "Wood Fireplace";

// Array length
console.log(amenities.length); // 5

Essential Array Methods

const prices = [130, 150, 120, 180, 140];

// push — add to end
prices.push(160);
console.log(prices); // [..., 160]

// pop — remove from end
const last = prices.pop();
console.log(last); // 160

// includes — check if value exists
console.log(prices.includes(150)); // true

// indexOf — find the position of a value
console.log(prices.indexOf(120)); // 2

// slice — get a portion (does not modify original)
const firstThree = prices.slice(0, 3); // [130, 150, 120]

// splice — remove/insert items (DOES modify original)
prices.splice(1, 1); // remove 1 item at index 1

// join — turn array into a string
const list = ["Meteora", "Elati", "Pertouli"];
console.log(list.join(", ")); // "Meteora, Elati, Pertouli"

// reverse
console.log([1,2,3].reverse()); // [3, 2, 1]

// sort
console.log([30, 5, 100].sort((a, b) => a - b)); // [5, 30, 100]

Array Iteration Methods (used constantly)

const locations = [
  { name: "Meteora",    km: 22 },
  { name: "Elati",      km: 30 },
  { name: "Pertouli",   km: 54 },
  { name: "Palaiokarya",km: 35 }
];

// forEach — loop over every item (no return value)
locations.forEach(loc => {
  console.log(loc.name + " is " + loc.km + " km away");
});

// map — create a NEW array by transforming each item
const names = locations.map(loc => loc.name);
console.log(names); // ["Meteora", "Elati", "Pertouli", "Palaiokarya"]

// filter — create a NEW array with only items that pass a test
const nearby = locations.filter(loc => loc.km < 40);
console.log(nearby); // Meteora, Elati, Palaiokarya

// find — return the FIRST item that passes a test
const meteora = locations.find(loc => loc.name === "Meteora");
console.log(meteora); // { name: "Meteora", km: 22 }

// some — true if AT LEAST ONE item passes
console.log(locations.some(loc => loc.km > 50)); // true (Pertouli = 54)

// every — true if ALL items pass
console.log(locations.every(loc => loc.km > 10)); // true

// reduce — condense array to a single value
const totalKm = locations.reduce((sum, loc) => sum + loc.km, 0);
console.log(totalKm); // 141

Objects

An object stores related data as key-value pairs. While an array is like a numbered list, an object is like a named record.

// Create an object
const property = {
  name: "Dream Chalet",
  bedrooms: 3,
  bathrooms: 2,
  rating: 9.8,
  petsAllowed: true,
  address: {                    // nested object
    city: "Trikala",
    country: "Greece"
  },
  amenities: ["WiFi", "Fireplace"], // array inside object
  getDescription: function() {     // function inside object = method
    return this.name + " — " + this.bedrooms + " bedrooms";
  }
};

// Access values
console.log(property.name);          // "Dream Chalet"   (dot notation)
console.log(property["bedrooms"]);   // 3                (bracket notation)
console.log(property.address.city);  // "Trikala"        (nested access)
console.log(property.amenities[0]);  // "WiFi"
console.log(property.getDescription()); // "Dream Chalet — 3 bedrooms"

// Add a new property
property.phone = "+30 6976908838";

// Delete a property
delete property.petsAllowed;

// Check if property exists
console.log("rating" in property); // true

Destructuring

A cleaner way to extract values from arrays and objects.

// Object destructuring
const { name, bedrooms, rating } = property;
console.log(name);     // "Dream Chalet"
console.log(bedrooms); // 3

// With rename
const { name: propertyName, rating: score } = property;
console.log(propertyName); // "Dream Chalet"

// With default value
const { minStay = 2 } = property; // 2 (property.minStay doesn't exist)

// Array destructuring
const [first, second, ...rest] = ["Meteora", "Elati", "Pertouli", "Palaiokarya"];
console.log(first);  // "Meteora"
console.log(second); // "Elati"
console.log(rest);   // ["Pertouli", "Palaiokarya"]

Loops

// for loop — classic, when you need the index
for (let i = 0; i < 5; i++) {
  console.log("Night " + (i + 1));
}

// for...of — loop over array values (cleanest for arrays)
const amenities = ["WiFi", "Fireplace", "Parking"];
for (const item of amenities) {
  console.log(item);
}

// for...in — loop over object keys
const property = { name: "Dream Chalet", rooms: 3, rating: 9.8 };
for (const key in property) {
  console.log(key + ": " + property[key]);
}
// name: Dream Chalet
// rooms: 3
// rating: 9.8

// while — loop while condition is true
let count = 0;
while (count < 3) {
  console.log("Count: " + count);
  count++; // ALWAYS increment or you get an infinite loop!
}

// Spread operator — expand array/object
const moreAmenities = [...amenities, "Pool", "Garden"];
const updatedProperty = { ...property, rating: 9.9 }; // copy + override
Common mistake: Using forEach when you need a return value. forEach always returns undefined. Use map when you need a new array, filter when you need a subset, find when you need one item.

Foundation 5

The DOM — Controlling the Page

The DOM (Document Object Model) is the browser's internal representation of your HTML page as a tree of objects. JavaScript uses the DOM to read and change anything on the page — text, styles, attributes, entire elements.

Think of it this way: HTML is the blueprint, the DOM is the actual built building, and JavaScript is the renovator who can change anything in the building at any time.

Selecting Elements

// querySelector — returns the FIRST matching element (or null)
const title   = document.querySelector("h1");            // by tag
const nav     = document.querySelector(".nav");           // by class
const btn     = document.querySelector("#book-btn");      // by id
const heroBtn = document.querySelector(".hero .btn");     // nested selector

// querySelectorAll — returns ALL matching elements (NodeList)
const cards   = document.querySelectorAll(".card");
const links   = document.querySelectorAll("nav a");

// Loop over NodeList
cards.forEach(card => {
  card.style.opacity = "0";
});

// Convert to Array (for array methods like .map, .filter)
const cardsArray = Array.from(document.querySelectorAll(".card"));

// Older methods (still work, less flexible)
const el   = document.getElementById("hero");       // by id
const els  = document.getElementsByClassName("card"); // by class

Reading and Changing Content

const title = document.querySelector("h1");

// Read text content (plain text, no HTML)
console.log(title.textContent); // "Dream Chalet"

// Set text content (safe — escapes HTML)

// Read/set HTML content (can include tags)

console.log(box.innerHTML); // "3 bedrooms"
box.innerHTML = "NEW content"; // ⚠ only use with trusted content

// Reading/setting attributes
const img = document.querySelector("img");
console.log(img.getAttribute("src"));        // "hero.jpg"
img.setAttribute("src", "new-hero.webp");
img.setAttribute("alt", "Dream Chalet exterior");

// data- attributes (used a lot with GSAP and JS)

card.dataset.active = "true";               // sets data-active="true"

Changing CSS Styles

const nav = document.querySelector(".nav");

// Inline styles (camelCase for hyphenated properties)
nav.style.backgroundColor = "#0e0b08";
nav.style.padding = "12px 2rem";

// Read a computed style (what the browser actually renders)

// Add a class

Foundation 6

Events — Making Things Interactive

Events are things that happen in the browser — a click, a key press, a scroll, a form submission, a mouse movement. JavaScript listens for these events and runs your code in response. This is the mechanism behind every interactive element on a website.

addEventListener — The Core Pattern

// Syntax: element.addEventListener("eventType", callbackFunction)
const btn = document.querySelector(".book-btn");

btn.addEventListener("click", function() {
  console.log("Button was clicked!");
});

// Arrow function (same thing, cleaner)
btn.addEventListener("click", () => {
  console.log("Button clicked!");
});

// Named function (best when you need to remove the listener later)
function handleClick() {
  console.log("Clicked!");
}
btn.addEventListener("click", handleClick);
btn.removeEventListener("click", handleClick); // remove it later

The Event Object

When an event fires, the browser automatically passes an event object to your callback. It contains information about what happened.

document.addEventListener("click", (e) => {
  console.log(e.type);       // "click"
  console.log(e.target);     // the exact element that was clicked
  console.log(e.clientX);    // X position of mouse
  console.log(e.clientY);    // Y position of mouse
});

// Prevent default browser behavior (e.g., stop form from submitting)
const form = document.querySelector("form");
form.addEventListener("submit", (e) => {
  e.preventDefault(); // stops the page from refreshing
  console.log("Form submitted via JS!");
});

// Stop event from bubbling up to parent elements
const card = document.querySelector(".card");
card.addEventListener("click", (e) => {
  e.stopPropagation(); // click won't reach parent listeners
});

// Keyboard (close gallery on Escape)

Event Delegation — One Listener for Many Elements

Instead of adding a listener to 50 cards, add one listener to their parent. This is more efficient and also works for elements added dynamically.

// ✗ Bad — 50 separate listeners
document.querySelectorAll(".gallery-img").forEach(img => {
  img.addEventListener("click", openGallery);
});

// ✓ Good — one listener on the parent
document.querySelector(".gallery-strip").addEventListener("click", (e) => {
  const img = e.target.closest(".gallery-img"); // find clicked image
  if (img) openGallery(img);
});
Performance tip: Add { passive: true } to scroll and touch event listeners. It tells the browser you won't call e.preventDefault(), allowing it to scroll without waiting for your JS to finish — much smoother on mobile.

ES6 (also called ES2015) was a major update to JavaScript in 2015. Since then, new features are added every year. These modern features make code shorter, cleaner, and more readable. All libraries in this project use them extensively.

Template Literals

const name    = "Dream Chalet";

Async JavaScript & Debugging

JavaScript runs one line at a time. But some operations — like fetching data from a server, reading a file, or waiting for an image to load — take an unknown amount of time. If JavaScript waited for these, the page would freeze. Asynchronous JavaScript solves this by saying: "start this task, and when it finishes, run this function."

The Problem — Synchronous Blocking

// If fetch() were synchronous (it's not), this would freeze the page
const data = fetch("https://api.example.com/data"); // ← page freezes here
console.log(data); // only runs after fetch completes

Callbacks — The Old Way

// setTimeout — run code after a delay (non-blocking)
console.log("1. Start");

setTimeout(() => {
  console.log("3. After 2 seconds");
}, 2000);

console.log("2. This runs immediately");
// Output: "1. Start" → "2. This runs immediately" → "3. After 2 seconds"

// The callback (arrow function) runs LATER, when the timer fires

Promises — A Better Way

// A Promise represents a value that will be available in the future
// It has 3 states: pending → fulfilled or rejected

const myPromise = new Promise((resolve, reject) => {
  // Simulate async work
  setTimeout(() => {
    const success = true;
    if (success) resolve("Data loaded!");  // success
    else reject("Something went wrong");   // failure
  }, 1000);
});

// Handle the result with .then() and .catch()
myPromise
  .then(result => console.log(result))  // "Data loaded!"
  .catch(error => console.error(error));

// fetch() returns a Promise
fetch("https://api.example.com/data")
  .then(response => response.json())    // parse JSON
  .then(data => console.log(data))      // use the data
  .catch(err => console.error(err));

async / await — The Modern Way

async/await is syntactic sugar over Promises — same thing underneath, but written to look synchronous. Much easier to read and write.

// Any function marked "async" returns a Promise
async function loadTranslations(lang) {
  // "await" pauses execution INSIDE this function until Promise resolves
  // The rest of the page keeps running normally
  const response = await fetch(`/locales/${lang}.json`);
  const data     = await response.json();
  return data; // resolves the Promise with this value
}

// Calling an async function
async function init() {
  const translations = await loadTranslations("el");
  console.log(translations.hero.title); // "Dream Chalet"
}
init();

// Real example — fetch iCal feed
async function fetchAvailability() {
  const response = await fetch("/api/ical");
  if (!response.ok) throw new Error("Failed to load calendar");
  const text = await response.text(); // iCal is plain text
  return parseICal(text);
}

Error Handling with try/catch

async function loadData(url) {
  try {
    const response = await fetch(url);
    if (!response.ok) {
      throw new Error(`HTTP error: ${response.status}`);
    }
    const data = await response.json();
    return data;

  } catch (error) {
    // Runs if fetch fails, JSON parse fails, or we threw manually
    console.error("Failed to load:", error.message);
    return null; // return a safe fallback

  } finally {
    // Always runs, whether success or failure
    hideLoadingSpinner();
  }
}

// Non-async: synchronous errors
try {
  const result = JSON.parse("invalid json {{{");
} catch (e) {
  console.error("Parse failed:", e.message);
}

Promise.all — Run Multiple Async Tasks in Parallel

// ✗ Sequential — waits for each before starting the next (slow)
const airbnb  = await fetchCalendar(AIRBNB_URL);   // 1 second
const booking = await fetchCalendar(BOOKING_URL);  // + 1 second = 2 total

// ✓ Parallel — both start at the same time (fast)
const [airbnb, booking] = await Promise.all([
  fetchCalendar(AIRBNB_URL),
  fetchCalendar(BOOKING_URL)
]);
// Both complete in ~1 second total

Loading Libraries from CDN

Before writing a single line of animation code, you need to understand how to load external libraries. A CDN (Content Delivery Network) is a server that hosts library files for you — no installation, no npm, no build tools. You just add a <script> tag to your HTML and the library is ready to use.

The Basic Pattern

Libraries are loaded in the <head> (for CSS) or just before the closing </body> tag (for JavaScript). Order matters — load dependencies before the code that uses them.

<!DOCTYPE html>
<html lang="el">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Dream Chalet</title>

  <!-- CSS libraries go in <head> -->
  <link rel="stylesheet" href="https://unpkg.com/maplibre-gl/dist/maplibre-gl.css">
  <link rel="stylesheet" href="css/style.css">
</head>
<body>

  <!-- Your HTML content here -->

  <!-- JS libraries: load order matters! -->
  <!-- 1. GSAP core first -->
  <script src="https://cdn.jsdelivr.net/npm/gsap@3.12.5/dist/gsap.min.js"></script>
  <!-- 2. GSAP plugins after core -->
  <script src="https://cdn.jsdelivr.net/npm/gsap@3.12.5/dist/ScrollTrigger.min.js"></script>
  <script src="https://cdn.jsdelivr.net/npm/gsap@3.12.5/dist/Flip.min.js"></script>
  <script src="https://cdn.jsdelivr.net/npm/gsap@3.12.5/dist/Draggable.min.js"></script>
  <!-- 3. Other libraries -->
  <script src="https://unpkg.com/@studio-freight/lenis@1.0.42/dist/lenis.min.js"></script>
  <script src="https://cdn.jsdelivr.net/npm/three@0.160.0/build/three.min.js"></script>
  <script src="https://unpkg.com/maplibre-gl/dist/maplibre-gl.js"></script>
  <script src="https://cdn.jsdelivr.net/npm/i18next@23.7.6/dist/umd/i18next.min.js"></script>
  <!-- 4. Your own scripts LAST -->
  <script src="js/main.js"></script>
</body>
</html>
Why load JS before </body>?
If you put scripts in <head>, the browser loads and executes them before the HTML is rendered. That means your JavaScript can't find elements like document.querySelector('.hero') because they don't exist yet. Placing scripts at the bottom ensures all HTML is parsed first.

Registering GSAP Plugins

GSAP plugins must be explicitly registered before use. This is a common beginner mistake — the plugin loads fine but animations don't work because registration was skipped.

// At the top of your main.js — always register plugins first
gsap.registerPlugin(ScrollTrigger, Flip, Draggable, SplitText);

// Now you can use them anywhere in your code
gsap.to(".hero", { opacity: 1, scrollTrigger: { trigger: ".hero" } });
Common mistake: Forgetting gsap.registerPlugin(ScrollTrigger) and wondering why scroll animations do nothing. Always register all plugins you plan to use, right at the top of your main JS file.

GSAP Core

GSAP (GreenSock Animation Platform) is the industry-standard JavaScript animation library. It animates anything — CSS properties, SVG, canvas, DOM attributes — with buttery-smooth performance across all browsers. Think of it as a remote control for every visual property on your page.

Why GSAP for Dream Chalet?
CSS animations are limited. GSAP lets us animate letter-by-letter text reveals, synchronize a dozen elements in a precise sequence, create magnetic button effects, and connect animations directly to scroll position — all without performance issues.

gsap.to() — Animate TO a value

The most common method. The element starts at its current state and animates to the values you specify.

// Move an element 100px to the right over 1 second
gsap.to(".box", { x: 100, duration: 1 });

// Fade in the hero title
gsap.to(".hero-title", { opacity: 1, duration: 1.2, ease: "power3.out" });

// Animate multiple properties at once
gsap.to(".nav", {
  backgroundColor: "#0e0b08",
  padding: "12px 2rem",
  duration: 0.4,
  ease: "power2.out"
});

gsap.from() — Animate FROM a value

The element starts at the values you specify and animates back to its natural CSS state. Perfect for entrance animations.

// Element slides up from 60px below and fades in
gsap.from(".section-title", {
  y: 60,
  opacity: 0,
  duration: 1,
  ease: "power3.out"
});

// Multiple elements, staggered (each 0.1s apart)
gsap.from(".amenity-card", {
  y: 40,
  opacity: 0,
  duration: 0.8,
  stagger: 0.1,  // 0.1s delay between each card
  ease: "power2.out"
});

gsap.fromTo() — Full control

You define both the start AND end state explicitly. Use when you need precise control.

gsap.fromTo(".hero-title",
  // FROM (starting state)
  { opacity: 0, y: 80, letterSpacing: "0.5em" },
  // TO (ending state)
  { opacity: 1, y: 0, letterSpacing: "0.08em", duration: 1.4, ease: "power4.out" }
);

GSAP Timelines

A Timeline is a sequence of animations played in order. Instead of using delay to chain animations (fragile and hard to maintain), a Timeline lets you build complex multi-step sequences that are easy to read, adjust, and control.

Creating a Timeline

// Create a timeline
const tl = gsap.timeline();

// Add animations in sequence — each starts after the previous finishes
tl.from(".nav", { y: -80, opacity: 0, duration: 0.8 })
  .from(".hero-title", { y: 60, opacity: 0, duration: 1, ease: "power3.out" })
  .from(".hero-subtitle", { y: 40, opacity: 0, duration: 0.8 }, "-=0.4")
  // "-=0.4" means start 0.4 seconds BEFORE the previous ends (overlap)
  .from(".hero-btns", { y: 30, opacity: 0, duration: 0.6, stagger: 0.15 }, "-=0.3");

Position Parameter

const tl = gsap.timeline();

tl.from(".a", { opacity: 0, duration: 1 })        // at time 0
  .from(".b", { opacity: 0, duration: 1 })        // at time 1 (after .a)
  .from(".c", { opacity: 0, duration: 1 }, "+=0.5") // 0.5s AFTER .b ends
  .from(".d", { opacity: 0, duration: 1 }, "-=0.3") // 0.3s BEFORE .c ends
  .from(".e", { opacity: 0, duration: 1 }, "<")     // SAME TIME as .d
  .from(".f", { opacity: 0, duration: 1 }, 2);      // exactly at 2 seconds

Timeline Defaults

// Set defaults for all animations in this timeline
const tl = gsap.timeline({
  defaults: {
    duration: 0.8,
    ease: "power2.out"
  }
});

// No need to repeat duration/ease on each animation
tl.from(".title", { y: 50, opacity: 0 })
  .from(".subtitle", { y: 30, opacity: 0 })
  .from(".btn", { scale: 0.9, opacity: 0 });

Controlling Timelines

const tl = gsap.timeline({ paused: true }); // start paused
tl.from(".menu-item", { x: -40, opacity: 0, stagger: 0.08 });

// Control it programmatically
document.querySelector(".menu-open").addEventListener("click", () => tl.play());
document.querySelector(".menu-close").addEventListener("click", () => tl.reverse());

// Other controls
tl.pause();          // freeze
tl.resume();         // continue
tl.restart();        // go back to start and play
tl.seek(0.5);        // jump to 0.5 seconds
tl.timeScale(2);     // play at 2x speed
tl.timeScale(0.5);   // play in slow motion
Pro tip: Use paused: true and trigger tl.play() on user interaction (click, scroll entry). This makes your animations intentional rather than playing on load automatically.

Chapter 5

GSAP Flip Plugin

Flip solves one of the hardest animation problems: animating an element that moves in the DOM. When a photo moves from a thumbnail in a grid to a fullscreen display, it changes parent, position, and size all at once. Without Flip, this looks like a teleport. With Flip, it appears to physically travel across the screen.

Used in Dream Chalet for: The gallery expansion — click a photo in the draggable strip, it morphs from its strip position to fill the screen. Click close, it morphs back. No jarring jumps.

How Flip Works (the concept)

Flip uses a technique called FLIP (First, Last, Invert, Play):

  1. First — record the element's current position/size
  2. Last — move it to its new position in the DOM
  3. Invert — instantly offset it back to the First position
  4. Play — animate it forward to the Last position

The result: the element appears to glide smoothly from A to B.

Magnetic Button Effect

    xTo(dx * 0.3);
    yTo(dy * 0.3);
  });

  btn.addEventListener("mouseleave", () => {
    // Snap back to original position
    xTo(0);
    yTo(0);
  });
});

Used in Dream Chalet for: The entire page scroll experience. Without Lenis, even the best GSAP animations can feel slightly jarring. With Lenis, everything flows as one cohesive experience.

Basic Setup

// Create Lenis instance

  duration: 1.2,         // scroll animation duration (seconds)
  easing: (t) => Math.min(1, 1.001 - Math.pow(2, -10 * t)), // expo ease
  orientation: "vertical",
  smoothWheel: true,     // smooth mouse wheel
  syncTouch: false,      // don't override native touch scroll (iOS)
});

// The animation loop — Lenis needs to be updated every frame
function raf(time) {
  lenis.raf(time);
  requestAnimationFrame(raf);
}
requestAnimationFrame(raf);

Connecting Lenis to GSAP ScrollTrigger

This is critical. Without this connection, ScrollTrigger uses the native scroll position, which conflicts with Lenis's virtual scroll. You MUST add these lines.

const lenis = new Lenis({ duration: 1.2 });

// Tell GSAP ticker to update Lenis on each frame

  lenis.raf(time * 1000); // GSAP time is in seconds, Lenis needs milliseconds
});

// Tell ScrollTrigger to use Lenis scroll values
lenis.on("scroll", ScrollTrigger.update);

// Disable GSAP's default lag smoothing (Lenis handles this)
gsap.ticker.lagSmoothing(0);

Three.js

Three.js is a JavaScript library that makes WebGL accessible. WebGL is a browser API that lets you draw 3D graphics using the GPU — but it's extremely low-level and complex to use directly. Three.js wraps it in a friendly API, so you can create 3D scenes, lights, cameras, and objects without needing to understand GPU shaders.

Think of it like this: WebGL is the engine, Three.js is the car.

Used in Dream Chalet for: A floating golden particle field rendered on a <canvas> element behind the About section and Attractions section — adds depth, luxury, and visual interest without heavy content.

The Core Concepts

ConceptReal-world analogyWhat it does
SceneA film setContainer that holds everything — objects, lights, camera
CameraThe film cameraDefines what we see and from what angle
RendererThe film projectorDraws the scene onto a <canvas> element
GeometryA wire sculptureThe shape of a 3D object (box, sphere, plane…)
MaterialPaint or textureThe surface appearance (color, shininess, texture…)
MeshThe finished sculptureGeometry + Material combined = a visible 3D object
PointsA star fieldGeometry rendered as individual dots — used for particles

Minimal Scene Setup

// 1. Scene — the container
const scene = new THREE.Scene();

// 2. Camera — PerspectiveCamera(fov, aspectRatio, near, far)
const camera = new THREE.PerspectiveCamera(
  75,                                    // field of view in degrees
  window.innerWidth / window.innerHeight, // aspect ratio
  0.1,                                   // near clipping plane
  1000                                   // far clipping plane
);
camera.position.z = 5; // move camera back so we can see the scene

// 3. Renderer — draws to a canvas
const renderer = new THREE.WebGLRenderer({
  canvas: document.querySelector("#three-canvas"),
  alpha: true,        // transparent background (show page behind it)
  antialias: true     // smooth edges
});
renderer.setSize(window.innerWidth, window.innerHeight);
renderer.setPixelRatio(Math.min(window.devicePixelRatio, 2)); // max 2x for performance

// 4. Create a simple cube
const geometry = new THREE.BoxGeometry(1, 1, 1);
const material = new THREE.MeshBasicMaterial({ color: 0xc9a96e });
const cube = new THREE.Mesh(geometry, material);
scene.add(cube);

// 5. Animation loop
function animate() {
  requestAnimationFrame(animate);
  cube.rotation.y += 0.01;
  renderer.render(scene, camera);
}
animate();

Creating a Particle System (Dream Chalet style)

// Particle system — 2000 floating golden dots
const particleCount = 2000;

// BufferGeometry is efficient for large numbers of points
const geometry = new THREE.BufferGeometry();

// Create random positions for each particle (x, y, z)
const positions = new Float32Array(particleCount * 3);
for (let i = 0; i < particleCount * 3; i++) {
  positions[i] = (Math.random() - 0.5) * 20; // random between -10 and +10
}
geometry.setAttribute("position", new THREE.BufferAttribute(positions, 3));

// PointsMaterial — how each particle looks
const material = new THREE.PointsMaterial({
  color: 0xc9a96e,   // warm gold
  size: 0.04,        // particle size
  transparent: true,
  opacity: 0.7,
  sizeAttenuation: true  // particles farther away appear smaller
});

// Points = Geometry + Material (like Mesh but for particles)
const particles = new THREE.Points(geometry, material);
scene.add(particles);

// Animate — slowly rotate the entire particle field
function animate() {
  requestAnimationFrame(animate);
  particles.rotation.y += 0.0003;
  particles.rotation.x += 0.0001;
  renderer.render(scene, camera);
}
animate();

Handle Window Resize

window.addEventListener("resize", () => {
  // Update camera aspect ratio
  camera.aspect = window.innerWidth / window.innerHeight;
  camera.updateProjectionMatrix();

  // Update renderer size
  renderer.setSize(window.innerWidth, window.innerHeight);
  renderer.setPixelRatio(Math.min(window.devicePixelRatio, 2));
});

Pause When Off-Screen (Performance)

let isVisible = false;

const observer = new IntersectionObserver(([entry]) => {
  isVisible = entry.isIntersecting;
});
observer.observe(document.querySelector("#three-canvas"));

  requestAnimationFrame(animate);
  if (!isVisible) return; // skip rendering when canvas is not visible

Disable on Low-End Devices

ical.js — Availability Calendar

ical.js is a JavaScript library that parses iCal (.ics) files — the calendar format used by Airbnb, Booking.com, Google Calendar, and virtually every other calendar system. By fetching the iCal feed from Airbnb and Booking.com, we can show a live availability calendar on the Dream Chalet site that updates automatically whenever a new booking is made.

Used in Dream Chalet for: A monthly availability calendar in the Pricing section. Green = available, grey = booked. Updates automatically from Airbnb and Booking.com. The owner never needs to manually update the website.

What is iCal?

iCal is a standard file format (.ics) for calendar events. Each booking platform generates a URL that serves a live .ics file for a property. Here's what it looks like inside:

BEGIN:VCALENDAR
VERSION:2.0
BEGIN:VEVENT
DTSTART:20260410
DTEND:20260415
SUMMARY:Reserved - Not available
END:VEVENT
BEGIN:VEVENT
DTSTART:20260420
DTEND:20260422
SUMMARY:Airbnb (HMXXXXXXXX)
END:VEVENT
END:VCALENDAR

Getting iCal URLs from Airbnb and Booking.com

Airbnb:
  1. Go to airbnb.com → Hosting → Calendar
  2. Click "Availability settings"
  3. Scroll to "Sync calendars"
  4. Click "Export calendar" → copy the .ics URL

Booking.com:
  1. Go to Extranet → Calendar
  2. Click "iCal" or "Sync" option
  3. Copy the export URL

Fetching and Parsing iCal

// Load ical.js from CDN:
// <script src="https://cdn.jsdelivr.net/npm/ical.js@1.5.0/build/ical.min.js"></script>

// iCal URLs (replace with real URLs from client)
const AIRBNB_ICAL_URL  = "https://www.airbnb.com/calendar/ical/YOUR_ID.ics";
const BOOKING_ICAL_URL = "https://ical.booking.com/v1/export?t=YOUR_TOKEN";

// CORS note: fetching from a different domain requires a proxy on GitHub Pages
// Use a free CORS proxy for now:
const PROXY = "https://corsproxy.io/?";

async function fetchBookedDates() {
  const bookedDates = new Set(); // stores "YYYY-MM-DD" strings

  // Fetch both calendars in parallel
  const [airbnbRes, bookingRes] = await Promise.allSettled([
    fetch(PROXY + encodeURIComponent(AIRBNB_ICAL_URL)),
    fetch(PROXY + encodeURIComponent(BOOKING_ICAL_URL))
  ]);

  for (const result of [airbnbRes, bookingRes]) {
    if (result.status !== "fulfilled") continue;
    const text = await result.value.text();

    // Parse with ical.js
    const parsed = ICAL.parse(text);
    const comp   = new ICAL.Component(parsed);
    const events = comp.getAllSubcomponents("vevent");

    events.forEach(event => {
      const vevent = new ICAL.Event(event);
      const start  = vevent.startDate.toJSDate();
      const end    = vevent.endDate.toJSDate();

      // Add every date in the range to the set
      const current = new Date(start);
      while (current < end) {
        bookedDates.add(current.toISOString().split("T")[0]); // "YYYY-MM-DD"
        current.setDate(current.getDate() + 1);
      }
    });
  }

  return bookedDates;
}

async function renderCalendar(year, month) {
  const bookedDates = await fetchBookedDates();
  const calendarEl  = document.querySelector(".availability-calendar");
  calendarEl.innerHTML = "";

  // Month header
  const monthNames = ["Ιανουάριος","Φεβρουάριος","Μάρτιος","Απρίλιος",
    "Μάιος","Ιούνιος","Ιούλιος","Αύγουστος","Σεπτέμβριος",
    "Οκτώβριος","Νοέμβριος","Δεκέμβριος"];
  const header = document.createElement("h3");
  header.textContent = `${monthNames[month]} ${year}`;
  calendarEl.appendChild(header);

  // Day grid
  const grid = document.createElement("div");
  grid.className = "calendar-grid";

  const firstDay  = new Date(year, month, 1).getDay();
  const daysInMonth = new Date(year, month + 1, 0).getDate();
  const today = new Date().toISOString().split("T")[0];

  // Empty cells for days before month starts
  for (let i = 0; i < firstDay; i++) {
    grid.appendChild(Object.assign(document.createElement("div"), { className: "day empty" }));
  }

  // Day cells
  for (let day = 1; day <= daysInMonth; day++) {
    const dateStr = `${year}-${String(month+1).padStart(2,"0")}-${String(day).padStart(2,"0")}`;
    const cell    = document.createElement("div");
    cell.textContent = day;

    if (dateStr < today)         cell.className = "day past";
    else if (bookedDates.has(dateStr)) cell.className = "day booked";
    else                          cell.className = "day available";

    grid.appendChild(cell);
  }

  calendarEl.appendChild(grid);
}

SEO (Search Engine Optimization) is how you make Google find your site, understand it, and rank it high. The goal: A technically perfect site that Google can crawl, understand, and trust — plus a compelling appearance in search results that makes people click.

Rule 1 — Semantic HTML Structure

Use the correct HTML tags for their purpose: <header>, <nav>, <main>, <section>, <footer>. Avoid putting everything in <div>.

Why: Google's crawler reads your HTML like a book. Semantic tags say "this is navigation", "this is the main content". Divs say nothing — it's a book with no chapters.

<!-- BAD -->
<div class="top"><div class="links">...</div></div>
<div class="stuff"><div class="text">...</div></div>

<!-- GOOD -->
<header>
  <nav>...</nav>
</header>
<main>
  <section aria-labelledby="about-heading">
    <h2 id="about-heading">About Dream Chalet</h2>
  </section>
</main>
<footer>...</footer>

Rule 2 — One <h1> Per Page, Proper Hierarchy

Why: Google uses headings as a table of contents. Multiple <h1> tags confuse it. Never skip levels (don't jump from <h1> to <h4>).

<h1>Dream Chalet Trikala — Vacation Rental</h1> <!-- Only ONE -->

  const ring  = document.querySelector(".cursor-ring");
  const label = document.querySelector(".cursor-label");

  const ringY = gsap.quickTo(ring, "y", { duration: 0.5,  ease: "power3.out" });
  const lblX  = gsap.quickTo(label,"x", { duration: 0.5,  ease: "power3.out" });
  const lblY  = gsap.quickTo(label,"y", { duration: 0.5,  ease: "power3.out" });

  document.addEventListener("mousemove", (e) => {
    dotX(e.clientX); dotY(e.clientY);
    ringX(e.clientX); ringY(e.clientY);
    lblX(e.clientX); lblY(e.clientY);
  });

  // State: hoverable link/button
  document.querySelectorAll("a, button, [data-cursor]").forEach(el => {
    el.addEventListener("mouseenter", () => {
      gsap.to(ring, { scale: 1.8, opacity: 0.5, duration: 0.3 });
    });
    el.addEventListener("mouseleave", () => {
      gsap.to(ring, { scale: 1, opacity: 1, duration: 0.3 });
      label.style.opacity = "0";
    });
  });

  // State: gallery drag
  const strip = document.querySelector(".gallery-strip");
  if (strip) {
    strip.addEventListener("mouseenter", () => {
      label.textContent = "Drag";
      label.style.opacity = "1";
      gsap.to(ring, { scale: 2.5, duration: 0.3 });
    });
    strip.addEventListener("mouseleave", () => {
      label.style.opacity = "0";
      gsap.to(ring, { scale: 1, duration: 0.3 });
    });
  }

  // State: gallery image view
  document.querySelectorAll(".gallery-img").forEach(img => {
    img.addEventListener("mouseenter", () => {
      label.textContent = "View";
      label.style.opacity = "1";

function trapFocus(modal) {
  const focusable = modal.querySelectorAll(
    "a, button, input, [tabindex]:not([tabindex='-1'])"
  );
  const first = focusable[0];

    }

}

7. Google Analytics 4 — Event Tracking

GA4 tracks who visits, where they come from, and what they do. The client can see how many people click "Book on Airbnb" vs WhatsApp, which photos they view most, and where they leave. This is how you prove the site works.

// js/analytics.js — called only after cookie consent
function initTracking() {
  if (typeof gtag === "undefined") return;

  // Track all booking button clicks
  document.querySelectorAll("[data-track]").forEach(el => {
    el.addEventListener("click", () => {
      gtag("event", "booking_click", {
        platform: el.dataset.track,   // "airbnb" | "booking" | "whatsapp" | "viber"
        location: el.dataset.location // "nav" | "contact" | "sticky"
      });
    });
  });

  // Track gallery opens
  document.querySelectorAll(".gallery-img").forEach((img, i) => {
    img.addEventListener("click", () => {
      gtag("event", "gallery_open", { image_index: i });
    });
  });

  // Track language switches
  document.getElementById("lang-toggle").addEventListener("click", () => {
    gtag("event", "language_switch", {
      from: i18next.language,
      to: i18next.language === "el" ? "en" : "el"
    });
  });

  // Track scroll depth (25%, 50%, 75%, 100%)
  const milestones = [25, 50, 75, 100];
  const reached = new Set();
  window.addEventListener("scroll", () => {
    const pct = Math.round(
      (window.scrollY / (document.body.scrollHeight - window.innerHeight)) * 100
    );
    milestones.forEach(m => {
      if (pct >= m && !reached.has(m)) {
        reached.add(m);
        gtag("event", "scroll_depth", { percent: m });
      }
    });
  }, { passive: true });
}
